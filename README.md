# Домашнее задание №2 (JavaScript)

В данном репозитории выполнены базовые практические задания по изучению типов данных, оператора `typeof`, объектов и массивов в JavaScript.

---

## 📋 Условия задания

1. **Создать переменные разных типов данных:**
   - Строка (`string`) — имя
   - Число (`number`) — возраст
   - Логическое значение (`boolean`) — например, `isStudent`
   - `null` — намеренное отсутствие значения
   - `undefined` — переменная без присвоенного значения
2. **Вывести каждую переменную в консоль.**
3. **С помощью `typeof` вывести тип каждой переменной.**
4. **Создать объект `person`** с полями: `name`, `age`, `isStudent`.
5. **Вывести в консоль информацию о персоне** в одном сообщении вида:  
   `"Меня зовут Али, мне 20 лет."` (значения берутся из созданного объекта).
6. **Создать массив из 5 любимых фильмов/игр/книг** и вывести его в консоль.

---

## 🚀 Как запустить проект

### Вариант 1. С помощью Node.js (в терминале)

Убедитесь, что установлен Node.js, и выполните:

```bash
node index.js
```

### Вариант 2. В веб-браузере

1. Откройте файл `index.html` в любом браузере (Google Chrome, Firefox, Safari, Edge).
2. Откройте панель разработчика (нажав `F12` или `Ctrl + Shift + I`) и перейдите во вкладку **Console**.
3. Результат также автоматически дублируется в блок на самой странице.

## 💡 Особенности и полезные заметки

- **`typeof null`**: в JavaScript оператор `typeof null` возвращает строку `"object"`. Это признанная историческая особенность (баг первой версии языка), сохраненная для обратной совместимости.
- **Шаблонные строки (Template Literals)**: для формирования сообщения о персоне используется синтаксис с обратными кавычками `` `Меня зовут ${person.name}, мне ${person.age} лет.` ``, что делает код более чистым и читаемым.
